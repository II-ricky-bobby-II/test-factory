# Agent Instructions

## Product Identity

Test Factory is the canonical product name. Do not introduce or preserve `QA Farm` in user-facing UI, page titles, aria labels, tests, or docs except when explicitly describing legacy reference material.

## UI Design Guidance

Before changing UI, read `docs/design/README.md` and follow the design documents in that folder. The app should use the Test Factory design system: cream paper surfaces, dark technical panels where appropriate, red-orange emphasis, forest-green status accents, bold editorial display type, mono metadata, visible borders, and readable responsive layouts.
